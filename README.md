# 🗣️ Speech-to-Text API Integration

## 📌 Introduction
This project converts **spoken words into text** using a Speech-to-Text API. It captures audio input from the user, sends it to the API for processing, and returns the transcribed text.

## 🚀 Features
✅ Converts speech to text in real-time  
✅ Supports multiple languages  
✅ Integrates with a Speech-to-Text API (e.g., Google Cloud, Microsoft Azure, or OpenAI Whisper)  
✅ Provides accurate transcription with noise filtering  
✅ Simple and intuitive UI
